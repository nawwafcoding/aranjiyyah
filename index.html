    المعجم

    كل قاعدة نمطٌ على النص المطبَّع (بلا تشكيل، وبهمزات موحّدة)، ومعها أصلها الأجنبي وبديلها وأمثلةٌ تُختبر آليًّا. تُحرَّر القواعد في ملف YAML واحد، فيقدر على الإضافة إليها من لا يكتب الشيفرة.

    في GitHub

    الأداة نفسها تعمل في سطر الأوامر وفي GitHub Actions، فتعلّق على السطور المعنيّة في كل طلب دمج يمسّ نصًّا عربيًّا.

    سطر الأوامر

    ثبّت الحزمة ثم افحص ملفًّا أو مجلدًا.

    pip install git+https://github.com/nawwafcoding/aranjiyyah
aranjiyyah check docs/ --min-severity medium
aranjiyyah fix مقال.md --write
aranjiyyah attest "يلعب دورا"

    طلبات الدمج

    أضف هذه الخطوة إلى سير العمل في أي مستودع.

    - uses: actions/checkout@v4
  with: { fetch-depth: 0 }
- uses: nawwafcoding/aranjiyyah@v0
  with:
    fail-on: high
    sarif: aranjiyyah.sarif
